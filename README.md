📞 Contact Book Management System

A simple Contact Book Management System built in Python using Object-Oriented Programming (OOP). This console-based application allows users to manage their contacts through a menu-driven interface.

🚀 Features
➕ Add a new contact
📋 View all contacts
🔍 Search a contact by name
❌ Delete a contact
🖥️ Simple menu-driven interface
🧱 Built using Python classes and objects
🛠️ Technologies Used
Python 3
Object-Oriented Programming (OOP)
📂 Project Structure
Contact-Book-Management-System/
│
├── main.py

▶️ How to Run

Clone the repository:
git clone https://github.com/your-username/Contact-Book-Management-System.git

Navigate to the project folder:
cd Contact-Book-Management-System

Run the program:
python main.py


📖 Menu Options
1. Add Contact
2. Show All Contacts
3. Delete Contact
4. Search Contact by Name
5. Exit
